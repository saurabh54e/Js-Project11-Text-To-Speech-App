# JavaScript Text to Speech Web App

Project 11 of my 30 JavaScript Projects Challenge.

A responsive Text to Speech Web App built using HTML, CSS, and Vanilla JavaScript that converts written text into speech using the Web Speech API, with support for multiple voices, languages, and accents.

---

## Features

- Convert text into speech
- Select from multiple available voices
- Support for different languages and accents
- Instant speech playback
- Simple and responsive user interface
- Easy-to-use text input and voice selection

---

## Architecture Approach

The application uses the Web Speech API to convert user-provided text into speech and manage available voice options.

- Users enter text into the input field
- JavaScript creates a `SpeechSynthesisUtterance` object containing the text
- Available voices are retrieved using the SpeechSynthesis interface
- Users select a voice to customize speech output
- The browser's speech synthesis engine generates and plays the speech
- Browser events help manage voice availability and interface updates

## Tech Stack

- HTML5

- Vanilla JavaScript
- Web Speech API
- SpeechSynthesis API
